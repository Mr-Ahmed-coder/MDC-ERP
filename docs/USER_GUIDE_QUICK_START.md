# MDC ERP User-Friendly Quick Start

## Start with the top bar

The top bar is now the fastest way to work. Use **Search** or press `Ctrl+K` / `Cmd+K` to find patients, invoices, services, and modules without opening the sidebar. Use **＋ New** to register a patient, create an invoice, start a laboratory order, start a radiology study, or open Record Options. The menu only displays actions allowed for the signed-in role.

Use the grid button to open **All Modules**. It includes a searchable launcher for every module available to the current role. On mobile, use the menu button to open the sidebar and tap outside the sidebar to close it.

## Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+K` or `Cmd+K` | Open global search |
| `Ctrl+Shift+K` | Open All Modules |
| `Alt+P` | Patients |
| `Alt+I` | Invoices |
| `Alt+L` | Laboratory |
| `Alt+R` | Radiology |
| `Alt+A` | Accounting |
| `Alt+H` | Dashboard |
| `Esc` | Close an open dialog or launcher |

Shortcuts are disabled while typing in an input or text area.

## Personal navigation

Use the star control to add the current page to **Favorites**. Use the clock control to reopen recently viewed records. Favorites and recent records are stored per user, which makes common workflows faster without changing the role permissions.

## Record safety

Open **Record Options** to review archive history and restore eligible records. Archive is the preferred action when a record should disappear from active lists but remain available for audit. Financial and clinical records must be cancelled or archived through their domain workflow; they cannot be hard-deleted.

## Recommended daily workflows

Reception staff should begin at the Dashboard, use **＋ New → Register patient**, then open the patient record and follow the queue or referral workflow. Cashiers should use **＋ New → Create invoice**, verify the invoice before payment, and use the billing screen for receipts. Laboratory and radiology staff should use the corresponding quick action and then follow the visible workflow status. Accountants should use the Accounting dashboard and run reconciliation checks before closing a period.
