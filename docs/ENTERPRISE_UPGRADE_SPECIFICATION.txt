MDC Diagnostic ERP — Final Enterprise Upgrade & Production Hardening

You are upgrading the existing MDC Diagnostic ERP into a highly secure, scalable, flexible, user-friendly Healthcare ERP/HIS platform.

IMPORTANT RULE

Do NOT rebuild the system from scratch.

Do NOT remove or break existing working modules.

First inspect the existing codebase, database models, routes, APIs, permissions, workflows, migrations, tests, UI and integrations.

Then improve the existing architecture incrementally.

Preserve all existing functionality unless a change is required for security, data integrity, usability, performance, or architectural consistency.

---

1. SECURITY HARDENING — CRITICAL

Make the entire system production-grade.

Authentication

Implement:

- Strong password policy
- Secure password hashing
- Account lockout/rate limiting
- Brute-force protection
- Login attempt tracking
- Session rotation after login
- Secure logout
- Session timeout
- Password expiration policy configurable by administrator
- Mandatory password change for first login
- Mandatory password change after administrator reset
- Optional/mandatory 2FA for sensitive roles

Remove all default credentials

Never ship production with:

- admin123
- default passwords
- development credentials
- hardcoded secrets
- hardcoded database passwords

Generate secure credentials during first installation.

All secrets must come from environment variables or a secure secret-management mechanism.

If required production secrets are missing, production startup must fail safely.
