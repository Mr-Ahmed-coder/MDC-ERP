MDC Diagnostic ERP — Final 9.0 → 10.0 Enterprise Upgrade

OBJECTIVE

Upgrade the existing MDC Diagnostic ERP Enterprise Spec from its current advanced state into a production-grade, enterprise-level Healthcare ERP/HIS.

The existing system already contains extensive healthcare, accounting, inventory, procurement, HR, radiology, laboratory, API, reporting and administration functionality.

IMPORTANT

DO NOT rebuild the application from scratch.

DO NOT remove existing working functionality.

DO NOT duplicate existing modules.

First inspect the current codebase and identify what already exists.

Only implement missing, incomplete, inconsistent, insecure or weak areas.

All existing functionality must continue to work after the upgrade.
